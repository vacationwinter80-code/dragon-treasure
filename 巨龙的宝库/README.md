# 巨龙的宝库

原生 HTML、CSS 和 JavaScript 制作的单机回合制网页游戏。

## 开始游戏

直接双击 `index.html`，或在本目录运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 规则

- 巨龙与圣骑士各有 10 点生命。
- 每局双方各获得 5颗随机石头；每只手至少有 1颗魔法宝石。
- 魔法宝石造成 2点伤害，普通石头不造成伤害。
- 玩家每次选择一颗背面石头并揭示；揭示后石头消耗。
- 玩家与英雄轮流行动；局内石头耗尽后进入下一局。
- 对局共 5局。任何一方生命归零立即获胜；5局结束后比较生命值，平局则判平。

## 隐藏信息实现

石头真实类型只保存在 JavaScript 内部对象 `type` 字段中。界面始终只渲染统一石头背面；玩家选择后才将对应石头揭示并消耗。英雄决策只从其未揭示的自身石头中随机选择，不读取石头类型，也不读取玩家石头。

## 文件

- `index.html`：页面结构和对话框
- `style.css`：桌面与手机响应式界面
- `game.js`：状态、随机资源、行动、电脑决策与胜负逻辑
